Hiruko. Game Design

Beskrivning

Hiruko är ett 2D pixel-art dungeon crawler inspirerat av japansk mytologi. Spelet följer Hiruko, en Fortune kami som har förlorat sina gudomliga krafter och måste återfå dem genom att utforska världen, besegra fiender och lösa musikbaserade pussel.

Jag utvecklade spelet helt själv och ansvarade för hela processen, från koncept, research och visuell design till spelmekaniker, UI, leveldesign, implementation i Godot och användartester. Eftersom det var mitt första egna spelprojekt fokuserade jag på att skapa en mindre, spelbar prototyp där centrala system kunde testas och förbättras iterativt.

Min roll: Game Design, UX/UI, Visual Design, Level Design, User Testing och Implementation.

Verktyg: Godot 4.7.2, GDScript och AI-baserade verktyg.

Combat och spelmekanik

En central del av designen var att koppla musik till både combat och problemlösning. Spelarens olika inputs spelar toner som används för abilities. Samma system används även för att lösa musikpussel i spelvärlden. På så sätt blir musiken en aktiv del av interaktionen i stället för enbart ljuddesign.

Musikbaserade pussel

Musiksystemet används också för att skapa pussel som spelaren behöver lösa för att ta sig vidare. Det ger spelaren möjlighet att använda samma mekanik på olika sätt och knyter samman spelets strider, utforskning och problemlösning.

UX, UI och användartester

Genom användartester utvecklade jag bland annat rörelsekontroller, dash, combat, progression, feedback och bossens svårighetsgrad. Testerna visade också att musikpusslen behövde tydligare vägledning utan att själva lösningen blev enklare.

Därför implementerade jag mål, hints och visuell feedback för att hjälpa spelaren att förstå vad som förväntades och hur den kunde komma vidare, samtidigt som utmaningen behölls.
